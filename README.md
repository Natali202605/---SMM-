# Лендинг-портфолио

Небольшой рабочий лендинг на чистом HTML/CSS/JS.

## Что внутри

- `index.html` — основная страница лендинга
- `styles.css` — стили
- `script.js` — рабочая логика формы
- `assets/images/hero-photo.png` — фото на главной странице
- `портфолио.htlm` — исходная большая версия страницы (оставлена как архив)

## Как запустить

1. Откройте `index.html` в браузере.
2. Для локальной разработки можно использовать Live Server в Cursor/VS Code.

## Функционал

- адаптивный лендинг (hero, услуги, контакты);
- форма заявки с валидацией;
- сохранение заявок в `localStorage` (ключ `leads`).

## Что можно улучшить дальше

- подключить отправку заявок в Telegram-бота/почту;
- вынести тексты в JSON/CMS;
- добавить мини-админку просмотра лидов.
